## Функционал
Берём за условие, что Киномир - это вымышленный кинотеатр, который располагается в Санкт-Петербурге, на трёх адресах. То есть всего три кинотеатра. В каждом кинотеатре по два зала. Схема залов идентична в каждом кинотеатре.
<img width="1920" height="1036" alt="image" src="https://github.com/user-attachments/assets/f6e0ce91-d2f8-47b6-b8b2-96dcaa151515" />
<img width="1920" height="1040" alt="image" src="https://github.com/user-attachments/assets/f2b6072a-d74e-48f5-a52e-1723a1885fcd" />

Место на данный сеанс можно забронировать, указав номер телефона и адрес электронной почты.
<img width="1920" height="1038" alt="image" src="https://github.com/user-attachments/assets/73f1fd35-1617-4968-846d-4450efaa2c0d" />

Можно посмотреть фильмы, идущие сейчас в прокате.
<img width="1920" height="1039" alt="image" src="https://github.com/user-attachments/assets/71b51ace-c565-4ba0-a38b-9dbc10daee92" />

Нажав на карточку фильма, идущего в прокате, можно посмотреть информацию о нём.
<img width="1920" height="1038" alt="image" src="https://github.com/user-attachments/assets/d9c2db01-4bf4-465d-9ccf-410a2a49805b" />

Frontend веб-приложения выполнен при помощи фреймворка Vue. Backend написан на языке C#.

На данный момент веб-приложение развёрнуто локально.
